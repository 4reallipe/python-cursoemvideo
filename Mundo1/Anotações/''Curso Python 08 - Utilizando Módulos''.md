## O que é?

São as bibliotecas, que nos permitem utilizar novos comandos e funcionalidades. Para utilizar(importar) tais bibliotecas, é preciso chamar elas com "```import (nome da biblioteca)```" fazendo com que importe tudo dessa biblioteca. Para Importar somente algo em específico, é preciso usar "```from (nome da biblioteca) import (coisa esfecífica desejada)```"
ex:
```python
#importar tudo
import bebida
import doce 

#importar algo específico
from bebida import café, refrigerante
from doce import pudim
```
