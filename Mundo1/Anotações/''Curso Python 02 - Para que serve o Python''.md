# De onde vem o Python?

##### História:
Nasceu em Amsterdam, em 1982 na CWI(Centro da Matemática e Ciência da Informação), sendo uma auxiliar da linguagem ABC. 
##### Python é:
- Linguagem de propósito geral
- Fácil e intuitivo
- Multiplataforma
- Batteries included
- Livre
- Organizada
- Orientada a Objetos
- Muitas Bibliotecas
##### Zen of Python
- Bonito é melhor do que feio.
- Simples é melhor que complexo.
- Complexo é melhor que complicado.
- Legibilidade conta.
- Erros nunca podem passar silenciosamente.
- Agora é melhor do que nunca.
- Se a implementação é difícil de explicar, então provavelmente é uma má ideia
- Se a implementação é fácil de explicar, então provavelmente é uma boa ideia.
